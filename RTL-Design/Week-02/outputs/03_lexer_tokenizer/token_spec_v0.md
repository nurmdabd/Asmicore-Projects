# Token Specification v0

| Token Type | Description |
|------------|-------------|
| KEYWORD | SystemVerilog keyword |
| IDENTIFIER | User-defined symbol |
| NUMBER | Numeric literal |
| OPERATOR | Arithmetic / logical operator |
| PUNCTUATION | Structural symbol |
| COMMENT | Single-line or multi-line comment |
| STRING | String literal |
| DIRECTIVE | Compiler directive |
| UNKNOWN | Unrecognized token |
